# GitHubリポジトリからの実装計画

## 現状確認

リポジトリURL: `https://github.com/nichicoma/lps/tree/main/app/gtnet/1`
- 404エラーが返っているため、プライベートリポジトリの可能性が高い
- 認証トークンが必要な可能性があります

## 実装が必要な要素

### 1. TOPページ (page-top.php)

#### ✅ 実装済み
- 統計オーバーレイ（業界実績、会員数、セキュリティ実績、導入企業数）
- ニュースフィード（カテゴリーフィルター付き）
- 事業紹介セクション（4カード）※5カードに変更が必要

#### 🔄 要修正・拡張
- **ヘッダーナビ**: 現在はSWELLの標準ナビ。以下のメニューに変更:
  - ホーム
  - 事業紹介
  - コラム
  - 会員ログイン（既に実装済み）
  - お問い合わせ
- **カルーセルMV**: 現在は単一のメインビジュアル。複数スライドのカルーセルに変更
- **統合ニュースフィード**: 大カテゴリタブを追加（現在は小カテゴリのみ）
- **事業紹介セクション**: 4カード → 5カードに変更

#### ❌ 未実装
- **「はじめての方へ」バナー**
- **サイドバー**:
  - 動画ライブラリ
  - 書式・テンプレート
  - データベース
  - 緊急連絡先
- **フッターの詳細構造**:
  - コンテンツ
  - 事業案内
  - 会社情報

### 2. 一覧ページ

#### ❌ 未実装
- **`/archives/`** - ニュース一覧（大カテゴリ+サブカテゴリフィルタ）
  - `archive.php` または `page-archives.php` として実装
  - 大カテゴリとサブカテゴリの2段階フィルター
- **`/movies/`** - 動画ライブラリ（カテゴリフィルタ）
  - `page-movies.php` として実装
  - カスタム投稿タイプ「動画」の可能性

### 3. 詳細ページ

#### ❌ 未実装
- **`/news/[id]/`** - ニュース詳細
  - `single.php` または `single-news.php` として実装
  - カスタム投稿タイプ「ニュース」の可能性、または通常の投稿として実装

## 実装手順

### ステップ1: GitHubからファイルをダウンロード（可能な場合）

```bash
# 認証トークンを使用してダウンロード
./scripts/download-page-from-github.sh <GITHUB_TOKEN>
```

### ステップ2: TOPページの拡張

1. 「はじめての方へ」バナーを追加
2. カルーセルMVを実装
3. サイドバーを実装
4. 事業紹介セクションを5カードに変更
5. 統合ニュースフィードに大カテゴリタブを追加
6. フッターを詳細化

### ステップ3: 一覧ページの実装

1. `/archives/` ページを作成
2. `/movies/` ページを作成

### ステップ4: 詳細ページの実装

1. `/news/[id]/` 詳細ページを作成

## 次のアクション

1. GitHub認証トークンが利用可能か確認
2. トークンがある場合: `./scripts/download-page-from-github.sh <TOKEN>` を実行
3. トークンがない場合: 要件に基づいて直接実装を開始
