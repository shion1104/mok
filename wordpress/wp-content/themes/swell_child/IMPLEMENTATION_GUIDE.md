## 🛠️ 3. SWELLでの実装手順

### 3.1 固定ページ（トップ）のブロック構成

WordPress管理画面で以下の手順で作成：

1. **固定ページ** → **新規追加**
2. タイトル: 「トップページ」など
3. パーマリンク: `/` に設定（設定 → 表示設定 → フロントページ）
4. ブロックエディタで以下の構成で作成：

```
【ブロック構成】

1. カスタムHTMLブロック
   → [gt_hero title="パチンコ企業の不正対策を専門とするセキュリティパートナー" subtitle="不正検知・防止システムの開発・運用で、業界の信頼を支えます" cta1_text="サービス詳細を見る" cta1_url="#services" cta2_text="お問い合わせ" cta2_url="/contact/"]

2. 見出しブロック（H2）
   → 「GTネットの強み」

3. カスタムHTMLブロック
   → [gt_strengths_slider]

4. 見出しブロック（H2）
   → 「不正対策サービス」

5. カスタムHTMLブロック
   → [gt_stats]

6. 見出しブロック（H2）
   → 「主要サービス」

7. カラムブロック（3カラム）
   → 各カラムにカードコンテンツ
   - カラム1: リアルタイム監視システム
   - カラム2: 不正パターン分析
   - カラム3: 緊急対応サポート

8. カスタムHTMLブロック
   → [gt_cta title="まずはお気軽にご相談ください" text="無料相談・資料請求を承っております。お気軽にお問い合わせください。" button_text="無料相談・資料請求" button_url="/contact/"]
```

### 3.2 ショートコードの使い方

#### `[gt_hero]` - ヒーローエリア

```html
[gt_hero 
  title="パチンコ企業の不正対策を専門とするセキュリティパートナー"
  subtitle="不正検知・防止システムの開発・運用で、業界の信頼を支えます"
  cta1_text="サービス詳細を見る"
  cta1_url="#services"
  cta2_text="お問い合わせ"
  cta2_url="/contact/"
]
```

#### `[gt_strengths_slider]` - 強みスライダー

```html
[gt_strengths_slider]
```

（パラメータなし。4つの強みが自動で表示されます）

#### `[gt_stats]` - 統計カウントアップ

```html
[gt_stats]
```

（パラメータなし。3つの統計が自動で表示されます）

#### `[gt_cta]` - お問い合わせCTA

```html
[gt_cta 
  title="まずはお気軽にご相談ください"
  text="無料相談・資料請求を承っております。お気軽にお問い合わせください。"
  button_text="無料相談・資料請求"
  button_url="/contact/"
]
```

### 3.3 カードスタイルの適用方法

サービスカードなどでカードスタイルを使用する場合：

```html
<div class="gt-card gt-fade-in">
  <h3 class="gt-card-title">リアルタイム監視システム</h3>
  <p class="gt-card-text">24時間365日、不正を監視します。</p>
</div>
```

### 3.4 アニメーションクラスの適用

スクロールアニメーションを適用する場合：

- **フェードイン**: `gt-fade-in`
- **左からスライド**: `gt-slide-in-left`
- **右からスライド**: `gt-slide-in-right`

例：
```html
<div class="gt-card gt-fade-in">
  <!-- コンテンツ -->
</div>
```

## 🎨 5. デザインガイドライン

### カラーパレット

```css
--gt-color-bg: #0a0e1a;          /* 黒ベース */
--gt-color-bg-light: #151a28;    /* ライト背景 */
--gt-color-text: #e8e8e8;        /* ライトテキスト */
--gt-color-text-muted: #a0a0a0;  /* ミュートテキスト */
--gt-color-accent: #2563eb;      /* アクセント青 */
--gt-color-accent-light: #3b82f6; /* ライトアクセント */
--gt-color-border: #1e293b;      /* ボーダー */
```

### タイポグラフィ

- **見出し**: 太字（600-700）、行間1.3
- **本文**: 通常（400）、行間1.8
- **余白**: セクション間120px（SP: 60px）

### 角丸・影

- **角丸**: 4px（控えめ）
- **影**: `0 2px 8px rgba(0, 0, 0, 0.1)`（薄く）
- **ホバー時**: `0 4px 16px rgba(37, 99, 235, 0.2)`

### アニメーション

- **速度**: 0.3s - 0.8s（控えめ）
- **イージング**: ease または ease-out
- **効果**: フェードイン、スライドアップ、カウントアップ
